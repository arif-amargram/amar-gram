# Amar Gram (আমার গ্রাম)

A starter website for the Amar Gram village information directory.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

This is only the initial frontend. Supabase connection, admin login, publishing workflow, and live data will be added in later steps. Never put a Supabase service-role key in frontend code.
